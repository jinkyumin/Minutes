# Meeting UI, ChatGPT Summary, and Notion Export Design

## Goal

Make the meeting minutes app easier to use at a glance, summarize meetings with OpenAI ChatGPT through a server-side API, and let users send saved meeting results to Notion.

## Approved UI

- The main screen has two equal-width panels: `회의 준비` and `회의 결과`.
- The old large step cards are removed.
- A small state pill appears beside the meeting status: `현재 단계: 회의 정보 입력`, `현재 단계: 회의 진행 중`, or `현재 단계: 결과 확인`.
- `회의 준비` contains only meeting date/time, attendees, controls, live transcript, and `Note`.
- The old `비고` field is removed.
- The live transcript area has a fixed max height and scrolls inside the panel as text grows.
- `Note` accepts typed or pasted text. Its content is automatically included in the LLM summary, saved record, copied text, and Notion export. There is no “add to transcript” button.
- `회의 결과` contains overview, key points, action items, `회의록 복사`, `Notion으로 보내기`, and a small Notion settings button.
- Recent records remain on the same screen. Clicking a record shows detail content.

## ChatGPT Summary

- Summary is generated by a Vercel server API route, not directly in the browser.
- Browser sends meeting date/time, attendees, transcript entries, and Note to `/api/summarize`.
- The server uses `OPENAI_API_KEY` and `OPENAI_MODEL`.
- Default model is `gpt-5.2-chat-latest` because the user requested ChatGPT-style summary.
- If `OPENAI_MODEL` is set to the older shorthand `chat-latest`, the server maps it to `gpt-5.2-chat-latest`.
- If OpenAI is not configured or fails, the app falls back to the existing local rule-based summary and shows a status message.
- The response shape is stable:
  - `overview: string`
  - `keyPoints: string[]`
  - `actionItems: string[]`

## Notion Export

- Browser sends the selected/saved meeting record to `/api/notion`.
- The server uses `NOTION_TOKEN` and either `NOTION_DATABASE_ID` from the environment or a database ID saved in local settings.
- The settings popup stores only the Notion Database ID in localStorage.
- Notion token stays server-side in Vercel environment variables.
- Export creates one Notion database page containing meeting date/time, attendees, overview, key points, action items, Note, and transcript.
- The app shows success or error status after sending.

## Environment Variables

- `OPENAI_API_KEY`: required for ChatGPT summary.
- `OPENAI_MODEL`: optional, defaults to `gpt-5.2-chat-latest`.
- `NOTION_TOKEN`: required for Notion export.
- `NOTION_DATABASE_ID`: optional if users enter a database ID in the app settings popup.

## Testing

- Unit tests cover request payload builders, local summary fallback, record normalization with `note`, and API handlers with mocked fetch.
- Existing tests must continue passing.
- `npm run build` must pass.
