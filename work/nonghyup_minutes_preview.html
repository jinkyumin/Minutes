농협 하나로마트 입점 관련 결제 시스템(VAN) 협의

원본 파일 농협 260401_111101.m4a
전사 파일 nonghyup_app_transcript.txt
주제 POS, VAN, 정산 구조 및 협상 방향 검토

회의 요약

농협 하나로마트 입점 시 다이소 POS와 셀프계산대 운영 구조를 유지하면서 결제 VAN을 농협VAN으로 전환해야 하는지 검토함.

NICE VAN 유지 또는 NICE 중계 서버를 통한 농협VAN 라우팅 가능성 우선 확인 필요. 농협VAN 직접 적용은 최후 대안으로 관리 필요.

핵심 판단

  • NICE VAN 유지가 안정성 측면 최우선
  • 농협VAN 라우팅은 현실적 협상 대안
  • 농협VAN 직접 적용은 비용, 일정, 장애 대응 리스크 큼

현재 롯데마트 운영 구조

장비셀프계산대는 다이소 장비 사용
유인 POS2대 운영: 다이소 POS, 마트 POS
마트 POS 용도현금 결제 중심
다이소 POS 용도셀프계산대 반품 전용
VANNICE VAN 사용
정산 흐름NICE가 카드 매출 자료 정리, POS 데이터와 대사 후 롯데에 전달
매출 인식롯데는 다음 날 전달받은 데이터를 통합 매출로 처리

농협 하나로마트 예상 구조

  • 셀프계산대 중심 운영 예상.
  • 장비는 다이소 장비 사용, 결제 주체는 농협 측 구조 가능성 있음.
  • 특정매입 계약 구조에서는 농협 측 매출 발생 필요.
  • 단순 임대수입만 발생하는 구조는 감사 이슈 가능성 있음.
  • 8월 오픈 예정 건부터 특정매입 계약 및 VAN 이슈 본격 적용 가능성 있음.

쟁점 및 리스크

농협VAN 사용 요구

  • 농협 측은 농협VAN 사용 요구 중인 것으로 파악.
  • 외부 영업 사례 부족으로 안정성 및 장애 대응 경험 불명확.
  • 특정 VAN 사용 강제 관점에서 공정거래법 이슈 가능성 있음.

기술/운영 리스크

  • POS 결제 통신 모듈 변경 필요.
  • 리더기/단말기 교체 및 인증 재취득 가능성 있음.
  • NICE와 농협VAN 병행 시 데이터 수신 및 대사 업무 증가 가능성 있음.
  • 장애 또는 데이터 미전송 발생 시 다이소 책임 전가 가능성 있음.

검토 대안

ANICE VAN 유지

  • 기존 NICE VAN 구조 유지.
  • 시스템 변경 최소화.
  • 운영 안정성 가장 높음.
  • 농협 설득 논리 필요.

BNICE 중계 라우팅

  • NICE 중계 서버 경유.
  • 농협 거래만 농협VAN 라우팅 검토.
  • 기존 구조 유지와 농협 명분 일부 충족 가능.
  • 기술 가능성 확인 필요.

C농협VAN 직접 적용

  • POS 결제 통신 직접 전환.
  • 단말기, 인증, 개발, 테스트 부담 큼.
  • 장애 대응 리스크 큼.
  • 최후 대안으로 관리 필요.
